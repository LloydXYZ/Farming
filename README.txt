DIZON FARM EQUIPMENT MANAGEMENT SYSTEM - FIXED VERSION

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html.
4. Install the Live Server extension in VS Code if needed.
5. Right-click index.html -> Open with Live Server.
6. Open the localhost page in Microsoft Edge.

FIXED FEATURES
1. NEXT STEP now validates the booking form and proceeds from Date & Location to Summary & Payment.
